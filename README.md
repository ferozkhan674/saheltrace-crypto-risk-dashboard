SahelTrace is a React-based prototype dashboard for visualizing cryptocurrency wallet risk, contextual identity links, and peer-network patterns in financial-crime and counter-terrorism investigation scenarios.

**Disclaimer:** This is a frontend prototype. The wallet analysis, risk scoring, sanctions flags, and network graph data are simulated for demonstration and learning purposes.

Built as a learning project using React. Some UI/code patterns were adapted from online references and customized into this investigative dashboard concept.
